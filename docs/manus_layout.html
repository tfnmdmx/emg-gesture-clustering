Manus 25 关节骨架 & 20 维 ergonomics 通道

本项目里用到的两个 Manus 数据契约： 渲染用的 manus_<hand>_skeleton（25 关节 XYZ+四元数） 与切分/聚类用的 manus_<hand>_ergonomics（20 维关节角）。

① 25 关节骨架（5 链 × 5 点）

每条手指 5 个端点 = 4 段骨头需要 5 个顶点： [anchor 基底 → MCP → PIP → DIP → tip]。 第 0/5/10/15/20 号是各指的掌侧 anchor（虚线掌轮廓相连）。

thumb 0–4 index 5–9 middle 10–14 ring 15–19 pinky 20–24

代码来源： emg_label/skeleton.py （SKELETON_CONNECTIONS / SKELETON_ROOT_INDICES）。 官方层级见 MANUS Skeleton 文档。

② 20 维 ergonomics 通道（4 通道 × 5 指）

布局：每指 4 通道 = [abd, MCP, PIP, DIP]， 顺序依次堆 4 指 + 拇指（拇指通道含义略不同）。
符号约定（项目内推断）：屈曲角 > 0 → 该段向掌心累计弯曲； 外展在掌平面（绕 z）张开。

手指 ch +0 ch +1 ch +2 ch +3 典型范围
thumb ch0
CMC 屈/展		 ch1
CMC abd		 ch2
MCP		 ch3
IP		 非屈曲通道近常值； IP/MCP 屈曲 0 ~ 1.4 rad
index ch4
abd（外展）		 ch5
MCP flex		 ch6
PIP flex		 ch7
DIP flex		 abd −0.5 ~ −0.15； MCP −0.5 ~ 1.5；PIP/DIP 0 ~ 1.4

注意：本项目里的 20 维通道命名是按数值范围推断的（见 3d-hand-pose-preview-design.md §4），不是 Manus 官方命名。 要 100% 权威映射请参考 Manus SDK 安装目录里的 Ergonomics 章节，或 Hand Measurement 页。

③ 25 关节 ↔ 20 通道 对照

同一只手用两套表示：骨架 25 点是几何位置（XYZ），ergonomics 20 维是关节角（rad）。 本项目里 切分/聚类只用 20 维角度（更紧凑且与手型一一对应）， 渲染优先用 25 关节 XYZ（不依赖 FK，无 torch 也能出图）； 处理后数据无 skeleton 时才用 20 维走 emg2pose FK 反推 21 个 landmark。
