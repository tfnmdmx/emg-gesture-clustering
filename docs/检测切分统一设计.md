# 手势检测 + 切分：统一设计规格（pose-spine + EMG-split，双信号一致性）

> 工程规格，非论文。目标：检测 + 切分，一段 = 一次成形运动 + 其后真正的稳定持姿（hold），右边界落在下一次运动 onset。落地于 `segment.py` 的 pose 路径 + `emg_label/pose_segmentation.py` + `emg_label/segmentation.py`，复用已有函数。

---

## 1. 核心思路

**pose-speed 当脊柱定义所有 onset/边界，EMG envelope 做三件事：确认 hold、补切（split）连续持姿、并对"被合并的背靠背持姿"主动否决欠切。** 协议是 运动→持姿→运动→持姿，且**没有公共 neutral**——连续两个 hold 是两个不同的非 neutral 成形姿态。因此 hold 必须按"低 pose-speed **AND** 低 EMG"检测（运动停了 + 肌肉松了），绝不能用"离某 neutral 的距离"。pose-speed 锐利、能抓 EMG 漏掉的慢/被动运动，所以由它画 onset；但当两个连续持姿之间姿态没回中、pose-speed 谷很浅时，pose 无法分开它们——而 **EMG 会在两次运动之间回落到 baseline**（肌肉放松），这是唯一能分开"连续非 neutral 持姿"的物理信号。所以 EMG 专职在 pose 合并出的 run 内部按"肌肉放松最深处"补切。这是**非对称融合**（不是对称投票）：pose 决定"哪里有运动/在哪 settle"，EMG 决定"两个被合并的运动之间该不该切、切在哪"，绝对关节位移 gate 决定"这是不是真手势"。

**为什么选这个核心而不是另外三个：** EMG-primary（设计A）把所有边界绑死在 EMG burst 列表上，而本数据**已记录的主导失效模式恰恰是 EMG-silent 的轻柔慢手势**（jm-0503 有 rest-level 低 EMG 的温和动作），一个漏掉的 burst 会同时丢一个手势并把它的两个邻居融成一段——方向错了。2-state HMM（设计C）的 Viterbi/emission 核在本仓库**根本不存在**（无 `viterbi`/`gauss_logpdf`，env 里没装 `hmmlearn`），且把 HOLD 锚在 p40（56% 样本是静止）会复活 velocity-valley 过切，复杂度与未验证必要性不划算。pose-primary 纯阈值（设计B）方向对，但单阈值 `static_motion_intervals` 在 25–60 deg/s 死区会让带肌张力的微抖持姿"永不闭合 run"而欠切。本设计取 D 的双信号互补脊柱，**强制补上 critique 指出的死区相对-settle 闭合、短 NaN 修复、R2 切点对齐与门控、背靠背持姿 EMG-否决（R7）、可冷启动的非循环校准 DAG**，并借设计A的清晰非对称融合表述。

## 2. 信号管线

两路一维信号，都在 2000 Hz EMG 采样轴上（pose 已由 `io_utils.load_npz` 线性插值上采样到该轴，物理带宽 ~75 Hz）。**全部复用现有函数，不改。**

| 信号 | 函数 | 单位 | 平滑窗 | NaN 处理 |
|---|---|---|---|---|
| `env` EMG 包络（确认/补切/否决） | `segmentation.emg_envelope(emg, fs, smooth_ms=150)` | a.u.（逐通道中位数去基线后跨 16ch 的 RMS） | 150 ms（=300 样本） | **内部 `nanmedian/nanmean`，EMG 的 NaN 已被正确吸收**——单通道 NaN 不破坏基线、整列 NaN 经 `nanmean` 跳过。**所以 EMG 路径无需额外 NaN 修复**，只对 pose 修复（见下）。 |
| `spd` pose-speed（脊柱） | `pose_segmentation.pose_speed(ja_filled, fs, pose_smooth_ms=250)` | deg/s（20 关节 `‖dθ/dt‖₂`） | 250 ms（=500 样本） | 见下面的"短 NaN 修复"——必须在 `pose_speed` 前填，否则 `uniform_filter1d` 把单帧 NaN 抹成 ±250ms（~500 样本）的 NaN-speed 空洞，被当作"运动"。 |

**新增 / 派生（一次性）：**

- **短 NaN 修复（关键鲁棒性修复，先于 `pose_speed`）**：`ja_filled = interpolate_short_nan_gaps(ja, fs, max_gap_s=0.20)`。语义精确定义（见 §10 helper 表）：
  - **逐通道（per-channel）独立**处理——单关节遮挡只修该列，不要求 20 关节同时有效；这样常见的"单指被另一只手挡住"不会拖累其它 19 个关节。
  - 对每列，找出连续 NaN run；**run 长度 ≤ `max_gap_s·fs`（0.20s=400 样本）且两端都有有限锚点**时，用两端线性插值（`np.interp`）填。
  - **录制头/尾的 NaN（无左/右锚点）不外推**，保持 NaN；长于 `max_gap_s` 的内部 gap 也保持 NaN。
  - 残余 NaN → `pose_speed` 产生 NaN-speed → `pose_hysteresis` 中 `np.isfinite(v)` 失败 → **按"运动"处理**（安全默认：未知区间不能升格成 settled hold）。
  - **`pose_nan_frac > 5%`** 的录制打 `review_flag='nan'`（QC）。
  - **为什么这步让单测 #12 通过：** "hold 内单帧掉帧不融两段"之所以成立，**正是因为这一步在 diff/smooth 前把单帧填掉**了；若不填，那一帧会变成 0.25s 的 NaN-speed 空洞被判为运动，把一个 hold 劈成两半（=融合两段的前置欠切）。故 #12 必须**断言填补步骤存在**；并配一个对照单测：一个 **> `nan_max_gap_s` 的长 gap** 仍（正确地）被当作运动、不被填、那 0.25s speed 仍被污染——这是已知且可接受的安全行为。
- **`rest = np.nanmedian(ja, axis=0)`**（20-向量，deg）：**仅用于 apex 帧的偏离排序**，绝不当 neutral 检测器（协议无 neutral）。注意现有 `segment.py` 用 `np.median`（非 nan 版）——迁移到 `np.nanmedian` 以兼容残余 NaN。
- **关节位移（gate 特征，非时间序列）**：任意窗 `[a,b)` 的 `pose_range = ‖nanmax(ja[a:b]) − nanmin(ja[a:b])‖₂`（deg）。**NaN-fraction guard（关键安全修复）**：`nanmax/nanmin` 在**全/几乎全 NaN 窗**上返回 NaN，而 `NaN < 15` 为 `False`——会让一个 NaN 满布的 MOTION run **错误地通过** gate（与安全默认相反）。故 gate 实现为：
  ```
  finite_frac = mean(all-finite-rows in ja[a:b])
  if finite_frac < min_finite_frac(=0.5):  return DROP   # NaN 太多→丢/打 'nan'，不放行
  rng = norm(nanmax - nanmin);  return DROP if (not isfinite(rng) or rng < pose_min_range)
  ```
  用于录制级（`rec_pose_range`）和 per-segment 绝对 gate，两处共用此 guard。
- **不计算全局 xcorr lag**：已确认在准周期数据上锁到反相（lag≈−0.6s, corr≈0.22, 0/143 ok）。任何 EMG/pose 对齐只做**局部 per-event**（见 §3 R6），且**仅作描述性诊断**——见 §3 末"lag 的混淆说明"。

## 3. 检测算法（状态机 + 显式融合规则）

两台**独立**状态机，融合前互不可见对方输出。

### Detector A — EMG burst（直接复用 `segmentation.segment_emg`，不改）
`auto_thresholds` 在 `env` 上做 Otsu：rest 模 + action 模，`enter = rest_center + 0.8·(valley−rest_center)`，`exit = rest_center + 0.4·(valley−rest_center)`（迟滞 enter>exit）。2-state `REST↔BURST`：`env>=enter` 进 BURST，`env<exit` 回 REST。`filter_segments` 合并间隔 `<min_rest_gap_s` 的 burst、丢弃短于 `min_action_s` 的 burst。
> 输出：filtered burst 区间列表 `bursts=[(bs,be),…]`、`enter`、`exit_e`。
> **EMG-rest 的唯一定义（全文统一）：** `EMG-rest = env < exit_e`（连续 envelope 阈下区），**不是** "filtered burst 的补集"。理由：`filter_segments` 会合并/丢弃 burst，其补集会把"被丢弃的 sub-`min_action` 激活"也算进 rest，而那些区间 env 其实 `>= exit_e`（肌肉并未放松）。R3 的 hold 确认、R2 的"干净 rest 间隙"、R7 的"hold 内 EMG 活动"**三处都用 `env<exit_e`**，不混用补集。
> 注意校准措辞要对齐真实代码：阈值锚点是 `rest_center = median(env[env<=valley])`（仅 sub-valley 样本的中位数），**不是**整段 env 的中位数。

### Detector B — pose 静止/运动迟滞机（**新写**，替换单阈值 `static_motion_intervals`）
2-state 迟滞机 `STATIC↔MOVING`，**绝对 deg/s 阈值**（修复 robust_threshold 相对阈值降到噪声底的 A5 失效）：

- **STATIC→MOVING**：`spd >= move_enter`（默认 60 deg/s）。
- **MOVING→STATIC（双判据闭合，关键修复死区欠切）**：满足以下**任一**并持续 `>= min_static_s`(0.35 s)：
  1. **绝对**：`spd <= move_exit`（默认 25 deg/s）；**或**
  2. **相对-settle**：`spd <= max(move_exit, settle_frac·peak_run)`（`peak_run` = 本 run 内 spd 峰值，`settle_frac`=0.25）。
  这条相对判据**只在 run 已打开后生效、下界永远被 `move_exit` 钳住**，因此既能闭合落在 25–60 deg/s 死区的"带张力微抖持姿"，又不会复活"相对阈值降到噪声底造 phantom"的 A5 bug。
- MOVING run 短于 `min_motion_s`(0.20 s) → 丢弃（抖动）。STATIC run 短于 `min_static_s`(0.35 s) → 不算真 hold，**并入相邻 MOVING run**（=死区/速度凹陷的 dip-merge，直接消灭 velocity-peak 的 2× 过切）。
> 输出：交替的 MOTION run `[ms,me)` 与 HOLD 平台 `[hs,he)`。

### 显式融合规则（pose 脊柱，EMG 确认+补切+否决）

- **R0 绝对位移 gate**：`rec_pose_range < pose_min_range`(15 deg)（经 NaN-fraction guard）→ 整段录制静止，返回 0 段（异常：长时间静止）。每个 MOTION run 若窗内 gate 判 DROP → 丢弃（噪声 bump / NaN 满布）。
- **R1 onset 列表**：候选 motion onset = Detector B 每个 MOTION run 的起点 `ms`。pose 当脊柱，因为它抓 EMG 漏的慢/被动运动（binding fact）。
- **R2 EMG 补切（仅对 pose 合并的超长 run）**：对每个 MOTION run `[ms,me)`，只有当**同时满足**：(a) run 长 `> pose_long_seg_s`(2.5 s)（永不 settle）**且** (b) run 内 burst 中心 ≥2 个**且** (c) 这些 burst 之间至少有一个 `>= min_rest_gap_s` 的**干净 EMG-rest 间隙**（`env<exit_e` 连续段）——才补切。切点放在该间隙内 `env` argmin（肌肉放松最深处）**再 `snap_to_speed_min` 到最近的 pose-speed 局部极小**（落在真实减速点而非任意中段；带界搜索，见 §10）。每个子段重跑位移 gate，不过则丢。若肌肉持续激活（无 rest 间隙）→ §7 的 valley-split fallback（仅此处允许）。**常规 run 不切**（避免 velocity-peak 过切）。
- **R3 hold 确认 = 一致性**：每段 hold 平台 `[me, next_onset)`（pose 静默区 `spd<=move_exit`）与 **EMG-rest（`env<exit_e`）** 重叠 `>= hold_confirm_s`(0.30 s) 时 `both_quiet=True`，标 `hold_agreement∈{both, pose_only}`。
- **R4 类型化分歧（不丢弃，打标；与 R3 用不同信号，勿混淆）**：本规则只看 **MOTION run** 上的 EMG，命名 `emg_in_motion`（≠ R3 的 `both_quiet`，后者看 **HOLD** 上的 pose∩EMG-rest 重叠）：
  - pose MOTION run 内**无** EMG burst（`emg_in_motion=False`）→ **慢/被动运动**：**保留为真段**（pose 对运动存在性权威），`fusion_type='pose_only'`, `review_flag='slow'`。← 这条直接修复设计A的 EMG-silent 欠切。
  - 有 EMG burst 重叠 MOTION run（`emg_in_motion=True`）→ `fusion_type='both'`（高置信）。
  - EMG burst **不**重叠任何 pose MOTION run 且其窗内位移 gate 判 DROP → **等长收缩/无位移用力**：**不产段**，仅由 `count_isometric` 记 `n_emg_only` 供 QC。
- **R5 投票汇总（仅 QC，不门控）**：`agreement_rate`（=`mean(hold_agreement=='both')`）、`n_pose_only`、`n_emg_only`、`emg_pose_lag_local_s` 中位数。**替换**已坏的全局 xcorr `lag_s/lag_flag` 列。`agreement_rate` 只做描述性指标，**不**当验收门槛（本数据 pose onset 远多于 EMG burst，大量段合法地是 pose_only）。
- **R6 局部 lag（绝不全局，仅描述性）**：`local_onset_lag` = (最近 EMG enter 上穿时刻) − (pose move_enter 上穿时刻)，**仅**在 onset 周围 `local_lag_window=[-0.30,+0.05] s` 窗内搜，且要求匹配的 EMG 上穿属于本段 burst（否则记 `None`，防准周期跨段误锁）。诊断列，门控为零。
- **R7 背靠背持姿否决（交替先验的主动纠错，关键欠切修复）**：见 §4 第 3 点——若一个 **常规长度**（`<= pose_long_seg_s`）的 hold 平台内含一段干净的 EMG burst（`env>=enter` 持续 `>= min_action_s`，且其前后各有 `>= min_rest_gap_s` 的 EMG-rest），说明这"一个 hold"其实跨了两个不同成形姿态之间的一次发力 → **强制在该 burst 处补切**（切点同 R2：`env` argmin → `snap_to_speed_min`）。这是 R2 触发不到的"正常长度 run 的背靠背欠切"的专用检测器。

> **lag 的混淆说明（不破坏设计，但措辞收敛为"描述性"）：** loader `io_utils._align_pose_to_emg` 把 `pose_t` 按 `emg_t[-1]/pose_t[-1]` 重标到 EMG end-time，叠加 pose ~75Hz 上采样 + 250ms 平滑，使 pose-speed 相对 EMG 有**未知的群延迟**——任何"EMG 领先 pose ~50ms"里有一部分是插值/时钟重标伪影，**不是生理**。因此：(1) R6 的 lag 只做**诊断列**，不门控、不被 medoid/聚类使用；(2) `snap_window_s`/`local_lag_window` 的设值理由从"生理 EMG-lead"弱化为"覆盖 pose 平滑群延迟（~125ms）+ 半 pose 帧（~3–6ms）+ 一点生理裕度"；(3) onset 取 `min(pose_foot, emg_enter)` 这一耦合的正当性**不靠 lag 估计**，而靠"快动作时 EMG 常先于可见 pose 位移发力、取更早者避免切头"这一保守取舍——即使 lag 估计被污染，取 min 也只会让边界稍微更早，安全。

## 4. 利用规则结构（交替先验当**主动约束**，不只是副产品）

协议的 静止↔运动 **严格交替**是硬约束。它不只是 Detector B 输出的形状（那只是被动副产品），还被 R7 升级为**能否决错误切分的主动规则**：

1. **交替（被动，by construction）**：Detector B 输出按构造交替 MOTION,HOLD,MOTION,…；段由"一个 MOTION run + 紧跟的 HOLD 平台"组成，右边界 = 下一个 onset。相邻段**无缝平铺时间轴**（`action_N.end == action_{N+1}.start`），每个成形持姿被恰好一段独占——这保证**不会过切**，但**不保证不欠切**。
2. **dip-merge 当先验**：单次运动内部的速度凹陷（reach→curl 两相手势、张力微抖）短于 `min_static_s` → 不闭合 run → 不产生伪 onset。这把"一个自然手势"钉成一段。
3. **R7：交替先验当 VETO（主动纠错，最危险欠切模式的专用检测器）**：本协议最危险的失效**不是过切而是背靠背持姿欠切**——两个不同成形姿态之间几乎没有可见 pose 位移（手没回中、只换了发力），pose-speed 谷浅到不闭合 run，于是两个 hold 被融成一段、其间的发力 blip 被 dip-merge 吞掉。**交替先验说"一个 hold 里不该有肌肉发力"**。R7 把它变成硬否决：**任何 hold 平台内出现干净 EMG burst（`>= min_action_s` 且前后有 EMG-rest）→ 违反交替先验 → 强制在该 burst 处切开**，即使 run 长度 `< pose_long_seg_s`（R2 触发不到）。这与 R2 互补：R2 修"超长永不 settle run 内的多次运动"，R7 修"正常长度 run 内被吞的背靠背换姿"。
4. **EMG 放松当"真边界"判据**：交替先验说"两段之间应有一次肌肉放松"。R2/R7 都只在"肌肉确实发力过且放松过"（干净 EMG-rest 包夹的 burst）时才补切——没有放松证据就不切，避免把一个手势的两相误切。
5. **计数先验当 sanity**：常规录制 ~每 119 s 出 ~35–50 段，仅用于 §9 体检，不门控。

## 5. 段定义与边界（样本级精确）

**一段 action = 一个 MOTION run + 其紧跟的真实稳定 hold，右边界落在下一次运动 onset。无 50 ms pad、无 0.5 s hold 上限。**

对第 k 段（onset 经 R2/R7 补切后）：

```
start_sample  = onset_k                       # = ms_k，pose MOTION run 起点（经 snap）
motion_start  = ms_k
motion_end    = me_k                           # MOVING→STATIC 闭合点（pose settled）
hold_start    = me_k
hold_end      = onset_{k+1}                     # 下一段 onset = 真实 hold 右界
end_sample    = onset_{k+1}                     # 末段见下面的"末段守护"
apex_sample   = apex_index_guarded(ja, start, hold_end, rest, fs)   # 整段内最大偏离-rest 帧
```

- `apex` 用现有 `features.apex_index`，在 `[start, hold_end)` 内取**平滑后最大关节偏离 rest** 的帧 = 最成形的姿态瞬间，**不是**峰速帧。验收要求 100% 落在 `[hold_start, hold_end)` 内（settled hold 内）。
- **apex 空窗守护（关键崩溃修复）**：`features.apex_index` 在 `start >= window_end` 时 `raise ValueError("empty window")`。因此**必须在调用前守护**：`apex_index_guarded(...)` = 若 `hold_end - start < 2`（被下一 onset 压成 ~1 帧 / 录制末尾 mid-motion）→ **不调用 apex_index**，置 `apex_sample = motion_start`（退而用运动起点，保证有效且单调），并打 `review_flag='long'`。**'long' 退化路径也走这条守护、绝不对 1 帧窗算 apex**（修正旧伪代码在 long 路径仍引用 apex 的不一致）。

**边界精确放置：**
- **START（motion onset）**：`spd` 上穿 `move_enter`(60) 处，由 `snap_to_motion_foot` **回溯**到其前最近的 `spd<=move_exit`(25) 样本（rising flank 的脚），把整段成形运动收进段内（迟滞：60 检测、25 锚定）。**回溯无 pre-onset 样本时（录制起始即在运动中）→ 钳到 0，不报错**（见 §10 helper 表）。若该段 EMG burst 起点更早（EMG 先发力），取 `min(pose_foot, emg_enter_crossing)`，避免快动作被切头。
- **END / 下一 START 共享**：同一公式算下一 onset，边界共享 → 无缝无重叠。
- **HOLD 内界**（`motion_end`/`hold_start`）：MOVING→STATIC 在 `min_static_s` dwell 测试后首次闭合的样本。
- **R2/R7 补切边界**：burst 间 `env` argmin → `snap_to_speed_min` 到最近 pose-speed 局部极小（带界）。
- **退化保护**：钳 `motion_end ∈ [motion_start+1, next_onset−1]`；apex 空窗守护见上。

**首段 / 末段 / mid-motion 边缘（显式规定）：**
- **首段**：协议是 move→hold，**首事件是无前置 hold 的 motion，正常**。若录制开局即在运动中（`spd[0] >= move_enter`）：`pose_hysteresis` 的 STATIC 分支在 `t=0` 即触发（`v>=move_enter`），`start=0`；`snap_to_motion_foot` 回溯找不到 `<=move_exit` 的脚 → 钳到 0。
- **末段**：协议末事件是无后继 onset 的 hold。`hold_end = end = min(n, last_hold_end(holds, n))`：`last_hold_end` 取**覆盖或紧邻末 onset 的那个 hold 平台的终点**，若末 hold 跑到 `n` 则取 `n`（见 §10）。若录制**末尾 mid-motion**（最后一个 MOVING run 被 `pose_hysteresis` 的 tail 子句以 `len(spd)` 闭合，没有后继 hold）→ `hold_start==hold_end==n` → 触发上面的 **apex 空窗守护**（apex=motion_start，flag='long'），不崩溃。

## 6. 参数表（全部物理单位 + 可冷启动的非循环校准 DAG）

### 6.0 校准依赖 DAG（先读这段：解决"循环/无法冷启动"）

旧表的多条配方**互相循环**（`move_exit` 要 confirmed hold，而 confirmed hold 经 R3 又要 `move_exit`；`min_static_s`/`min_motion_s` 要已切好的 hold/motion 时长）。冷启动时这些量都**还不存在**。正确顺序按下面三层 DAG，**只有第 0/1 层是冷启动需要的，第 2 层是可选的迭代精修**：

- **第 0 层 — 常量（不校准，固定）：** `fs=2000`, `smooth_ms=150`, `pose_smooth_ms=250`, `settle_frac=0.25`, `min_action_s=0.40`, `min_rest_gap_s=0.20`, `emg_enter_k=0.8`, `emg_exit_k=0.4`, `pose_min_range=15`, `pose_long_seg_s=2.5`, `max_hold_s=4.0`, `nan_max_gap_s=0.20`, `min_finite_frac=0.5`, `snap_window_s=0.15`, `local_lag_window=[-0.30,+0.05]`, `min_static_s=0.35`, `min_motion_s=0.20`, `hold_confirm_s=0.30`。
  - **`min_static_s`/`min_motion_s`/`hold_confirm_s` 改为常量**（不再写"略低于 hold/motion 时长 P5"那种循环配方）。它们是**纯时间裕度**，由平滑窗决定而非由切分结果决定：`min_motion_s=0.20` ≥ 250ms 平滑窗能可信分辨的最短运动；`min_static_s=0.35` > `pose_smooth_ms` 以确保 dwell 测的是真平台不是平滑余晖；`hold_confirm_s=0.30` = `min_static_s − pose_smooth_ms/2`（0.35−0.125≈0.225，向上取 0.30 留裕度）——**这就是旧表说的"减平滑余量"，现在给出明确数字**。这些常量在 §9 体检里**事后验证**（#3 #4），而**不是**靠它们去校准。
- **第 1 层 — 仅由 EMG 派生（冷启动唯一真正要算的两个 pose 阈值，且不依赖任何 pose 切分结果）：**
  这是唯一**genuinely bootstrappable** 的配方，**文档以它为准**。Detector A 独立于 pose，先跑它拿到 EMG-rest 区（`env<exit_e`），再用 EMG-rest 区**门控** pose-speed 取统计——pose 阈值**只从 EMG-rest-gated speed 派生，不从 hold 派生**（hold 此刻还不存在）：
  ```
  # cold_start_pose_thresholds(emg_list, ja_list, cfg) -> (move_enter, move_exit)
  rest_spd = []                          # 所有录制里"EMG 说肌肉松了"的样本的 pose-speed
  for emg, ja in calib_recordings:
      env = emg_envelope(emg, fs, 150)
      _, exit_e = auto_thresholds(env, 0.8, 0.4)
      spd = pose_speed(interpolate_short_nan_gaps(ja,fs,0.20), fs, 250)
      rest_mask = (env < exit_e) & isfinite(spd)
      rest_spd += list(spd[rest_mask])
  move_exit  = ceil(percentile(rest_spd, 99))      # EMG-rest 平台内 pose 噪声的 P99
  move_enter = 3 * percentile(rest_spd, 95)         # 落在 hold 噪声与最慢真运动之间
  assert move_exit < move_enter                      # 否则回退默认 25 / 60
  ```
  默认 `move_enter=60 deg/s` / `move_exit=25 deg/s` 是在校准集（见 §6.1）上跑出的典型值，作为 `assert` 失败时的回退。**注意：这里完全不需要 confirmed hold 或任何已切段**——EMG-rest 把"肌肉松了"的时刻独立标出来，那些时刻的 pose-speed 就是 hold 噪声的样本，无需先有 hold。
- **第 2 层 — 可选迭代精修（不是冷启动必需，仅当第 1 层阈值在 §9 体检不达标时）：** 用第 1 层阈值跑一遍 `segment_recording` 得到初版 motion/hold 段，再用这些段的经验分布**复核**（不是重设）常量：`P99(spd within emitted holds)` 应 `≈ move_exit`、`P5(emitted hold duration)` 应 `> min_static_s`、`P5(emitted motion duration)` 应 `> min_motion_s`。若严重偏离则手调并重跑——**最多 1–2 轮**，不做自动闭环（避免相对阈值漂移）。

## 7. 异常段处理（次级 post-processing）

主流程为**常规录制**调优；异常仅在 base 切分后兜底，绝不内联特判。

1. **长时间静止 / phantom（R0 绝对 gate）**：`rec_pose_range < 15 deg` → 0 段，`pose_static=1`。per-window gate 判 DROP（含 NaN 满布）→ 丢该 run。**永不用相对阈值**。
2. **动作太快无停顿（超长 run）**：MOTION run `> pose_long_seg_s`(2.5s) 且无内部 hold → `review_flag='long'`。
   - 若内含 ≥2 burst 且有干净 EMG-rest 间隙 → R2 在肌肉放松最深处补切（snap 到 pose 谷）。
   - 若肌肉持续激活（无 rest 间隙）→ **仅在此 flagged run 内**退回 `pose_segmentation.velocity_peak_segments`。**注意陷阱：** `velocity_peak_segments` 内部 prominence 用**整段信号的 MAD** 自算，**忽略传入的 `detect_thr`** 那一项——在 saturated（一直高速）的异常 run 上 MAD 极小，会**过切恰好这个异常 run**。因此 fallback 须：(a) 把 `detect_thr` 传为 `move_enter`（约束 height）；(b) **在调用前对该 run 内的 speed 子段单独算 MAD/prominence floor**，或直接传一个**绝对 prominence 下限**（=`0.5·move_enter`），不依赖 saturated 段的 MAD；(c) 每个子段重跑位移 gate，不满足则**保留为一整段 'long'**（宁可一段诚实长段，也不要 2× phantom 切——符合 §9#9"切成 >1 但诚实"）。
3. **背靠背持姿欠切（R7）**：常规长度 run 内 hold 平台含干净 EMG burst → 强制切（§4.3）。这是本协议**最危险的欠切**，由 R7 主动否决，不靠 run 长度触发。
4. **超长 hold**：hold `> max_hold_s`(4s) → 保段，`review_flag='long_static'`，不影响边界。
5. **慢/被动（pose_only，R4）**：保段，`review_flag='slow'`。
6. **等长收缩（emg_only，R4）**：不产段，`count_isometric` 记 `n_emg_only`。
7. **NaN 遮挡**：先短 NaN 修复（§2，逐通道、头尾不外推）；残余长 NaN 按运动；位移 gate 有 NaN-fraction guard；`pose_nan_frac>5%` 打 `review_flag='nan'`。
8. **lag QC**：全局 xcorr 从门控**移除**；仅 `emg_pose_lag_local_s` + `agreement_rate` 作**描述性**诊断列。

## 8. 为什么不默认用 velocity-peak 谷底切

velocity-peak（一个 pose-speed 峰一段、在谷底切超长 run）在**常规数据上 2× 过切**（clips/bursts=2.0）：一次自然手势常是两相（reach→curl）或带张力微抖，会产生 ≥2 个速度峰，于是被切成约 2 段，duration std 退化到 ~0.136（在切波形而非切语义）。本协议的真边界是"两次成形持姿之间"，由 dip-merge（短凹陷不闭合 run）+ EMG 放松证据（R2/R7）界定，而非每个速度峰。所以谷底切**只保留**给 §7.2 内部已 flagged 的"永不 settle 连续手势且无 rest 间隙"的退路；常规路径绝不使用，且调用时须按 §7.2 规避其 MAD-prominence 自过切陷阱。

**#8 ground-truth 缺口（诚实声明）：** 仓库**没有人工标注的运动起点时间戳**——`out_pose2/labels.csv` 与 `clips_labeled.csv` 的 `gesture_label` 只标**手势身份**（哪个手势，49 行），不标 onset 时刻；`clips.csv` 的 `gesture_label` 列全空。因此"onset 落在人标运动起点 ±150ms"**当前不可测**。#8 降级为：(a) **静止录制（`rec_pose_range<15`）出 0 段**——可自动测，保留为硬验收；(b) onset 精度只能**5 条 eyeball 目视**（看 overview.png onset 竖线是否压在 pose-speed 上升沿），**不是定量门槛**，除非未来在 webapp 里新增 onset 标注。

**#11 度量错配警告（关键，必须读）：** `cluster_traj.clip_traj_feature(ja, ms, me, …)` 的特征**只取 `motion_start_sample → motion_end_sample`（MOTION run 轨迹），完全不看 hold**。本设计的核心卖点是"捕获真实 hold"，但 silhouette **看不到 hold**——所以"silhouette ≥0.33"只验证 **motion-run 边界质量**，**不验证 hold 捕获**；它可能因与本设计核心无关的原因移动，甚至在 hold 捕获改善时保持不变。三选一处理（本设计取 **(a)+(b)**）：
- **(a) 明确声明** #11 仅验证 motion 边界，**不**当 hold 工作的验收门槛；
- **(b) 改 `cluster_traj`** 加一路 apex/hold 特征：在 `clip_traj_feature` 旁新增 `apex_pose_at(ja, apex_sample)`（取 apex 帧 ±50ms 中位姿，即复用 `features.apex_pose_feature` 的成形姿）拼到轨迹特征后，**这样 silhouette 才真正吃到 hold 的成形姿**；以此版 silhouette 作 hold 工作的下游验收。
- (c) 备选：若不改 cluster_traj，则 #11 从主验收门槛**降为旁证**。
- **结论**：#11 作为门槛**只对 (b) 改造后的特征成立**；未改造前 silhouette ≥0.33 仅为 motion 边界旁证，不算 hold 捕获的证据。

**新增单测（修正为与真实函数行为匹配）：**
- **dip-merge**：单运动含 <0.35s 内凹（speed 在凹处仍 >`move_exit` 或凹 dwell < `min_static_s`）→ `pose_hysteresis` 返回 **1** 个 run。
- **EMG-split（R2）**：5s 合成 run 含 3 个干净 burst（间有 `>min_rest_gap_s` 的 `env<exit_e`）→ **3** 段。
- **R7 背靠背**：一个 2s（`<pose_long_seg_s`）run，pose-speed 谷浅不闭合，但中段含一个 `>=min_action_s` 的 EMG burst 前后有 rest → R7 强制切成 **2** 段（专测最危险欠切；R2 此处不触发）。
- **死区闭合**：合成 run，`peak_run` 设到 ~200 deg/s，平台保持 **40 deg/s**（落在 `move_exit`=25 与 `move_enter`=60 之间的死区）持续 1s——断言此 run 闭合成 hold（成立条件：`40 <= max(move_exit, settle_frac·peak_run)=max(25, 0.25·200=50)=50` ✔，且 `move_enter=60>40` 不会重新触发运动）。**测试须把 `peak_run` 设到 `0.25·peak_run >= 40`（即 `peak_run>=160`）否则相对判据无效、测了个寂寞**。
- **NaN-in-hold（#12，断言填补步骤）**：hold 内插 **单帧 NaN** → **先经 `interpolate_short_nan_gaps` 填**（断言该帧填回有限值）→ `pose_speed` 无空洞 → 两 hold **不被**劈开/不被融两段。配对测：插一段 **>`nan_max_gap_s`(0.20s)** 的 NaN → **不填** → 那 0.25s speed 为 NaN → 该窗（正确地）被当运动。
- **位移 gate NaN guard**：一个 MOTION run 窗 90% 为 NaN → `nanmax−nanmin` 为 NaN → 断言 gate 判 **DROP**（修 `NaN<15==False` 误放行）。
- **excursion gate**：`rec_pose_range<15` → **0** 段。
- **apex 空窗守护**：`hold_end==hold_start`（末段 mid-motion）→ 不抛 `ValueError`，`apex_sample==motion_start`，`review_flag=='long'`。

def segment_recording(emg, ja, cfg):
    n = len(emg); fs = cfg.fs
    ja = interpolate_short_nan_gaps(ja, fs, cfg.nan_max_gap_s, cfg.min_finite_frac)
    env = emg_envelope(emg, fs, cfg.smooth_ms)                     # EMG NaN 已内部吸收
    spd = pose_speed(ja, fs, cfg.pose_smooth_ms)                   # deg/s 脊柱
    rest = np.nanmedian(ja, axis=0)                                # 仅 apex 排序

    if not seg_range_ok(ja, 0, n, cfg.pose_min_range, cfg.min_finite_frac):  # R0+NaN guard
        return [], dict(pose_static=1)

    bursts, env, enter, exit_e = segment_emg(emg, cfg)             # Detector A
    motion_runs, holds = pose_hysteresis(                          # Detector B (新)
        spd, fs, cfg.move_enter, cfg.move_exit,
        cfg.min_static_s, cfg.min_motion_s, cfg.settle_frac)

    onsets = []                                                    # R1 + R2
    for (ms, me) in motion_runs:
        if not seg_range_ok(ja, ms, me, cfg.pose_min_range, cfg.min_finite_frac):
            continue                                               # 噪声 bump / NaN 满布
        if (me-ms)/fs > cfg.pose_long_seg_s:                       # 超长 run → R2
            inner = [b for b in bursts if ms <= center(b) < me]
            gaps  = clean_rest_gaps(env, inner, exit_e, cfg.min_rest_gap_s, fs)
            if len(inner) >= 2 and gaps:
                cuts = [snap_to_speed_min(spd, env_argmin(env, g),
                                          cfg.snap_window_s, fs) for g in gaps]
                onsets += [ms] + [c for c in cuts
                                  if seg_range_ok(ja, c, me, cfg.pose_min_range,
                                                  cfg.min_finite_frac)]
            else:                                                  # 无 rest 间隙 → §7.2
                onsets += [ms] + valley_split_guarded(spd, ms, me, fs, cfg.move_enter)
        else:
            onsets.append(ms)                                      # 常规：一运动一 onset
    onsets = sorted(set(onsets))
    if not onsets:
        return [], dict(pose_static=0)

    # R7 背靠背否决：常规长度 run 的 hold 里有干净 burst → 在 burst 处补 onset
    onsets = inject_r7_splits(onsets, holds, bursts, env, enter, exit_e, spd, cfg, fs)
    onsets = sorted(set(onsets))

    actions = []                                                   # 建段
    for i, s in enumerate(onsets):
        s = snap_to_motion_foot(spd, s, fs, cfg.move_exit, cfg.snap_window_s)
        b = burst_starting_before(bursts, s)
        if b is not None:
            s = min(s, nearest_emg_enter(env, enter, s, cfg.snap_window_s, fs))
        e = onsets[i+1] if i+1 < len(onsets) else min(n, last_hold_end(holds, n))
        ms, me = motion_run_covering(motion_runs, s)
        me = clamp(me, s+1, e-1)
        hs, he = me, e                                             # 真实 hold
        apex, long_flag = apex_index_guarded(ja, s, he, rest, fs)  # 空窗守护
        emg_in_motion = any(overlap(b, (ms, me)) > 0 for b in bursts)        # R4
        both_quiet = (overlap_len(hold_plateau(hs, he, spd, cfg.move_exit),  # R3
                                  emg_rest_intervals(env, exit_e, n))
                      >= cfg.hold_confirm_s*fs)                    # 用 env<exit_e
        ftype = "both" if emg_in_motion else "pose_only"
        if long_flag:                 flag = "long"
        elif not emg_in_motion:       flag = "slow"
        elif (he-hs)/fs > cfg.max_hold_s: flag = "long_static"
        else:                         flag = ""
        lag = local_onset_lag(env, enter, spd, cfg.move_enter, s, fs,
                              cfg.local_lag_lo, cfg.local_lag_hi)   # R6 描述性
        actions.append(dict(start=s, end=e, motion_start=ms, motion_end=me,
                            hold_start=hs, hold_end=he, apex_sample=apex,
                            fusion_type=ftype,
                            hold_agreement=("both" if both_quiet else "pose_only"),
                            review_flag=flag, onset_lag_s=lag))

    qc = dict(pose_static=0,                                       # R5（仅诊断）
              agreement_rate=mean(a["hold_agreement"]=="both" for a in actions),
              n_pose_only=sum(a["fusion_type"]=="pose_only" for a in actions),
              n_emg_only=count_isometric(bursts, actions, ja,
                                         cfg.pose_min_range, cfg.min_finite_frac),
              emg_pose_lag_local_s=median([a["onset_lag_s"] for a in actions
                                           if a["onset_lag_s"] is not None]))
    return actions, qc


def pose_hysteresis(spd, fs, move_enter, move_exit, min_static_s,
                    min_motion_s, settle_frac):
    state, runs, start = "STATIC", [], 0
    quiet, peak_run = 0, 0.0
    min_static = int(round(min_static_s * fs))
    min_motion = int(round(min_motion_s * fs))
    for t, v in enumerate(spd):
        if state == "STATIC":
            if np.isfinite(v) and v >= move_enter:                 # NaN 不触发进运动
                state, start, peak_run, quiet = "MOVING", t, v, 0
        else:  # MOVING
            if np.isfinite(v):
                peak_run = max(peak_run, v)
            settle_lvl = max(move_exit, settle_frac * peak_run)    # 相对+绝对 二判据
            if np.isfinite(v) and v <= settle_lvl:                 # NaN 不算 settle=按运动
                quiet += 1
            else:
                quiet = 0
            if quiet >= min_static:                                # dwell=dip-merge
                end = t - quiet + 1
                if (end - start) >= min_motion:
                    runs.append((start, end))
                state, quiet = "STATIC", 0
    if state == "MOVING" and (len(spd)-start) >= min_motion:       # 末尾 mid-motion
        runs.append((start, len(spd)))
    holds = complement(runs, len(spd))
    return runs, holds


def inject_r7_splits(onsets, holds, bursts, env, enter, exit_e, spd, cfg, fs):
    """背靠背持姿欠切的主动否决（§4.3）。常规长度 hold 内出现干净 EMG burst → 切。"""
    extra = []
    for (hs, he) in holds:                                          # 每个 pose hold 平台
        if (he - hs)/fs > cfg.pose_long_seg_s:                      # 超长归 R2，跳过
            continue
        for (bs, be) in bursts:
            if not (hs <= center((bs, be)) < he):
                continue
            if (be - bs)/fs < cfg.min_action_s:
                continue
            # burst 前后须各有 >= min_rest_gap_s 的 EMG-rest（env<exit_e）
            if rest_run_before(env, exit_e, bs, cfg.min_rest_gap_s, fs) and \
               rest_run_after(env, exit_e, be, cfg.min_rest_gap_s, fs):
                cut = snap_to_speed_min(spd, env_argmin(env, (bs, be)),
                                        cfg.snap_window_s, fs)       # 切在肌肉放松最深处
                extra.append(cut)
    return list(onsets) + extra

**一句话总结：** pose-speed 双判据迟滞机当脊柱画 onset/边界（相对-settle 闭合修死区欠切、dip-merge 杀 velocity-peak 过切），EMG envelope 在 pose 合并出的超长 run（R2）和**正常长度 run 内被吞的背靠背换姿**（R7，本协议最危险欠切）处用"肌肉放松"补切并做 hold 确认，绝对 15deg 位移 gate（带 NaN-fraction guard）兜 phantom，慢手势按 pose_only 保留；pose 阈值**仅从 EMG-rest-gated speed 冷启动派生**（非循环、不需已切段），段 = 运动 + 真实 hold，右界落在下一 onset，无 pad、无 hold 上限；下游 silhouette 需改 cluster_traj 吃 apex 成形姿才真正验证 hold 捕获。
